# Email Security Analytics

## Project Overview

This project analyzes email security data to identify potential security threats, malicious email patterns, suspicious links, threat types, severity levels, and sender-domain activity.

The project follows an end-to-end data analytics workflow using Python, Exploratory Data Analysis (EDA), and Power BI.

## Objective

* Analyze email security patterns and characteristics
* Identify malicious and safe email patterns
* Analyze suspicious links and threat types
* Understand email severity distribution
* Analyze sender-domain activity
* Analyze email activity by hour and day
* Develop KPIs for security monitoring
* Perform data analysis using SQL
* Build an interactive Power BI dashboard for analysis and reporting

## Tools & Technologies

* Pandas

* Power BI

* DAX

## Dataset

The project uses an email security dataset containing approximately 10,000 email records.

The dataset includes information related to:

* Email subject and content
* Word and character counts
* Links and suspicious links
* Attachments
* Sender email and sender domain
* Sender reputation
* Recipient count
* Money-related indicators
* Urgency indicators
* Threat type
* Severity
* Email type
* Email activity by hour, day, and weekend

## Data Cleaning & Preparation

Python and Pandas were used to prepare the dataset for analysis.

The data preparation process included:

* Reviewing the dataset structure and data types
* Checking data quality
* Preparing relevant fields for analysis
* Cleaning and transforming data
* Preparing the final dataset for EDA, SQL analysis, and Power BI reporting

## Exploratory Data Analysis

Exploratory Data Analysis was performed using Jupyter Notebook to understand patterns and relationships within the email data.

The analysis included:

* Safe vs malicious email distribution
* Suspicious link analysis
* Money-related email indicators
* Threat type analysis
* Severity analysis
* Sender-domain analysis
* Email activity by hour
* Weekend and day-based analysis
* Feature relationships and comparisons

Machine learning classification models were also explored as part of the analytical process to evaluate email classification.

## Power BI Dashboard

An interactive Power BI dashboard was developed to provide a consolidated view of email security metrics and patterns.

### KPIs

The dashboard includes key metrics such as:

* Total Emails
* Malicious Emails
* Safe Emails
* Suspicious Link Emails

### Dashboard Visuals

The dashboard includes:

* Email Type analysis
* Threat Type analysis
* Severity analysis
* Suspicious Link analysis
* Top 10 Sender Domains by Email Volume
* Hour-based email activity
* Interactive slicers for filtering the analysis

### Power BI Development

* Power Query was used for data transformation and preparation.
* Data modeling was performed to support dashboard analysis.
* DAX measures were created for KPIs and analytical calculations.
* Interactive slicers were added to allow users to filter the dashboard dynamically.

## Key Analysis Areas

The project provides analysis of:

1. Overall email volume
2. Safe and malicious email distribution
3. Suspicious links across email types
4. Threat type distribution
5. Email severity levels
6. Sender-domain email volume
7. Email activity across different hours

## Key Findings

The analysis identified patterns in malicious and safe emails based on security-related indicators such as suspicious links, threat types, severity, sender domains, and email activity.

The Power BI dashboard provides an interactive way to explore these patterns and filter the analysis based on different security dimensions.
